# SD International Business Game

## Description
This is a turn-based business simulation game developed in Java.

The player manages a company called SD International. The goal is to complete projects by assigning employees and making strategic decisions while maintaining a positive cash balance.

The game evolves over turns and includes financial constraints, project management, and random events.

---

## Features

- Turn-based game engine  
- Employee hierarchy (Developer, Tester, Manager)  
- Project lifecycle (Planned → In Progress → Finished)  
- Assign employees to projects  
- Salary system (cash decreases each turn)  
- Win condition (complete all projects)  
- Lose condition (bankruptcy)  
- Random events (Market Crash, Bonus)  
- Save game to file  
- Console-based user interface
